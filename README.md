# JavaScript and JQuery Hacks

A collection of useful JavaScript and jQuery snippets and hacks for various web development tasks.

## Features and Demos

### 1. Filtering Table Rows based on Checkboxes
- **Description**: Filter rows of a table dynamically using checkboxes.
- **Demo**: `show-hide.html`
- **Key Files**:
  - `js/show-hide.js`
  - `css/show-hide.css`

### 2. Sync Multiple Lists with Multiple Values
- **Description**: Synchronize selections between multiple dropdown lists.
- **Demo**: `sync_multiple_lists.html`
- **Key Files**:
  - `css/sync_multiple_lists.css`

### 3. jQuery Accordion
- **Description**: Simple show/hide blocks using jQuery.
- **Demo**: `jquery_accordion_demo.html`
- **Key Files**:
  - `js/show-hide-accodion.js`
  - `css/show-hide-accordion.css`

### 4. Copy List Items and Checking for Duplicates
- **Description**: Copy items from one list to another while preventing duplicates. Includes a version compatible with IE11.
- **Demos**:
  - `list_copy_items.html` (Standard)
  - `list_copy_items_with_IE11.html` (IE11 compatible)

### 5. DataTables Date Sorting
- **Description**: Advanced date sorting for DataTables using Moment.js.
- **Demo**: `data-table-date-sorting.html`
- **Key Files**:
  - `js/datetime-moment.js`
  - `js/moment.min.js`
  - `js/jquery.dataTables_1_10.js`
  - `css/dataTable_sorting_on_date.css`

## Directory Structure

- `css/`: Stylesheets for various demos.
- `images/`: Image assets used in the demos.
- `js/`: JavaScript and jQuery library files, plus custom scripts.
- `*.html`: Individual demo pages for each hack.
